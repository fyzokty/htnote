## AI Orchestration

- The multi-agent pipeline runs only through `/orch`.
- Project rules shared by all agents live in `.ai/context/`; keep them the single source of truth.
- Do not read or edit `.ai/runtime/` or `.ai/logs/` unless the user asks about a specific task.
- Commit messages use an English lowercase type and scope with a Turkish description, for example `feat(products): Ürün listesi yenileme eklendi.`
- Branch names use `NNNN-type(scope)-slug` and are generated by `/orch`.
- `/orch` handles commits, pushes, and pull requests; do not intervene manually.
